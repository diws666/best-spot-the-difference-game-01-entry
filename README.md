A cozy harbor-at-dusk spot-the-difference game: find ten differences per level across three increasingly tricky levels before the timer runs out. Vanilla Canvas 2D + WebAudio synth, no libraries, no network requests.

## Run it with the run slug `best-spot-the-difference-game-20261121-0451`

```sh
best-spot-the-difference-game-20261121-0451
```
Serve locally: `node serve.ts`, then open http://localhost:8080. Click or use the arrow keys + Space to mark differences; H for a hint.
